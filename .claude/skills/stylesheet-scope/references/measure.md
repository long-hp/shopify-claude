# Measuring before and after

The goal is **mobile FCP / LCP**, not bytes. Bytes only predict. Always measure for real before concluding: the Dawn-style split once lowered the score while reducing bytes (see `why-not-dawn-split.md`).

## 1. Bytes (fast, no store needed)

```bash
node .claude/skills/stylesheet-scope/scripts/css-composition.mjs          # shared file: raw / gzip / brotli + by group
node scripts/xo-stylesheet.mjs --report                                   # scoped CSS: bytes per file, target liquid
```

Numbers for the report: `styles.css` gzip before and after; total scoped CSS; number of files kept shared because of AJAX.

Expected on an XO theme the size of base-3: shared file 60 KB gzip → 15–25 KB gzip depending on how much stays shared. What remains is atomic (generated by scanning the whole theme's liquid, ~45 KB raw) and core basehtml (`create-effects.scss` ~29 KB raw, mostly unused hover effects). Both are separate work; note them in the handoff if they look worth it.

## 2. Lighthouse (store without password, or a preview URL that already passed it)

Use the `lighthouse-audit` skill for both versions:

1. Before: the theme currently pushed. Run **5 times** mobile; record FCP, LCP, Speed Index, score.
2. After: push the theme with the plugin to a **different dev theme** (`shopify theme push -d`), same store, same content. Run 5 times.
3. Compare **mean and spread** of FCP / LCP. Scores swing ±5; only trust a difference larger than the spread.

If LCP does not improve or gets worse: check in Network that Shopify's generated file is in `<head>` and pushed via Early Hints, and that no section still carries a Dawn-style `stylesheet_tag` in `<body>`.

## 3. Correct styling (no numbers, but mandatory)

On the dev theme after installing:

- Home, collection, product, cart, search: nothing unstyled at a glance.
- Quick view, predictive search, add to cart (cart drawer / notification), variant change inside quick view, AJAX filter pagination.
- Theme editor: drag a rare section (bundle-builder, press-reviews) into home → styled as soon as the editor renders it.

Anything unstyled at one of those steps → that liquid file is scoped but its HTML arrives via AJAX → add its folder to `exclude` in `theme-config/stylesheet.config.json`, run `node scripts/xo-stylesheet.mjs` again.
