# SF-A11Y-02 — Visible focus state on every focusable element

Requirement and how to verify: `../references/feedback-ledger.md` → `SF-A11Y-02`.
Check type: heuristic + runtime

## Recipe (any theme)

One global focus-visible style with a two-tone ring (foreground outline + background halo) so it shows on any color scheme; draw it inset inside overflow scrollers; remove every `outline: none` on focus without a replacement.

## History

Each entry is one theme where this was fixed. On a theme built on the same base the files
are usually the same paths, so start from the newest entry; if the root cause differs, fix it
from the recipe above and add a new entry.

### Folio — R1 (2026-11-05)

- **Root cause:** The global focus ring was `color(primary)`, invisible on primary bands/buttons (manifesto marquee, brown CTAs).
- **Fix:** `outline: 0.2rem solid color(foreground)` + `box-shadow: 0 0 0 0.2rem color(background)` halo in `src/styles/base/focus.scss`. Inside `overflow` scrollers draw it inset. Also drop atomic `o:none|fv` (the quantity input had it).
- **Files:** `src/styles/base/focus.scss`, any `o:none|fv` class
- **Verify:** `scan-feedback.py --only SF-A11Y-02`; runtime: Tab across every color scheme.

### Folio — re-audit (2026-11-06)

- **Root cause:** Base field resets `input:focus` / `select:focus { outline: none }` have the same specificity as the global `input:focus-visible` ring and load later, so they killed it on every plain input/select. A dead `.xo-field-input:focus-within { outline: none }` sat in the footer signup.
- **Fix:** `:focus` → `:focus:not(:focus-visible)` (mouse only); dropped the unconditional `outline: none` on base `input`, `select` and `.xo-field-textarea__input`; removed the dead footer rule.
- **Files:** `src/snippets/field-input/field-input-base/field-input-base.global.scss`, `src/snippets/field-select/field-select-base/field-select-base.global.scss`, `src/snippets/field-textarea/field-textarea/field-textarea.global.scss`, `src/snippets/email-signup-footer/email-signup-footer.global.scss`
- **Verify:** `--only SF-A11Y-02` → MANUAL; runtime: Tab into search, newsletter, cart note, contact form.
