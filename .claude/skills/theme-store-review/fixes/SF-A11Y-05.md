# SF-A11Y-05 — Touch targets at least 24×24 CSS px

Requirement and how to verify: `../references/feedback-ledger.md` → `SF-A11Y-05`.
Check type: runtime

## Recipe (any theme)

Give small controls (swatches, dots, ×, ±) a ≥2.4rem hit area via `min-width/min-height` or padding, keeping the visual size.

## History

Each entry is one theme where this was fixed. On a theme built on the same base the files
are usually the same paths, so start from the newest entry; if the root cause differs, fix it
from the recipe above and add a new entry.

### Folio — R1 (2026-11-05)

- **Root cause:** Colour swatches were 15×15 (preset `swatches_width/height: 15`).
- **Fix:** `.xo-variant-image { min-width/min-height: 2.4rem }`; the visual chip keeps the preset size.
- **Files:** `src/snippets/field-variant-image/field-variant-image.global.scss`
- **Verify:** Runtime: measure dots, swatches, ×, ± at 390px.

### Folio — R1 re-audit (2026-11-06)

- **Root cause:** Two more sub-24px targets found by runtime measuring at 390px: the "+N" swatch-overflow quick-view trigger (16×12) and `product-card-2` text-link actions (`min-height: 0` → 18px tall).
- **Fix:** Recipe unchanged — `min-width/min-height: 2.4rem` on `.xo-variant-option-link xo-product-quick-view-trigger`; `min-height: 2.4rem` on `.xo-product-card-2__actions .xo-button-normal` (text-link look kept).
- **Files:** `src/snippets/product-helpers/product-cart-variant-option-link.global.scss`, `src/snippets/product-card/product-card-style-2/product-card-2.global.scss`
- **Verify:** `/collections/all` + `/cart` at 390px → "+1" 24×24, Quick view / Add to cart / Compare ≥24 tall.
