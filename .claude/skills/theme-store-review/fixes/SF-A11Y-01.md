# SF-A11Y-01 — Everything is keyboard reachable, including dropdown navigation

Requirement and how to verify: `../references/feedback-ledger.md` → `SF-A11Y-01`.
Check type: heuristic + runtime

## Recipe (any theme)

Every custom-element control (`xo-*-trigger`, prev/next, tabs) needs a focusable element: `role="button" tabindex="0"` plus Enter/Space handling, or a real `<button>` inside. Sweep for controls without tabindex or a focusable child.

## History

Each entry is one theme where this was fixed. On a theme built on the same base the files
are usually the same paths, so start from the newest entry; if the root cause differs, fix it
from the recipe above and add a new entry.

### Folio — R1 (2026-11-05)

- **Root cause:** Custom-element triggers (`<xo-tabs-trigger>` in notes-pyramid / tab-title) had no `tabindex`, so Tab skipped them.
- **Fix:** Add `role="button" tabindex="0"`; the theme's global keydown handler turns Enter/Space on `role=button` into a click. Sweep `<xo-*-trigger|prev|next>` without tabindex and without a focusable child.
- **Files:** `src/snippets/tabs/tab-title/**`, any `<xo-*-trigger>` markup
- **Verify:** `scan-feedback.py --only SF-A11Y-01`; runtime: Tab through header, mega menu, tabs, carousels.
