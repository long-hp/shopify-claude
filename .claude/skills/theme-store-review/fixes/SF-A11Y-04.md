# SF-A11Y-04 — Unique input IDs with matching `<label for>`

Requirement and how to verify: `../references/feedback-ledger.md` → `SF-A11Y-04`.
Check type: heuristic

## Recipe (any theme)

Every input gets an id unique per page (suffix section/block/line/variant id; distinct suffix for duplicated mobile/desktop/sticky copies) and a `<label for>` (visually hidden if needed). No empty `id` attributes.

## History

Each entry is one theme where this was fixed. On a theme built on the same base the files
are usually the same paths, so start from the newest entry; if the root cause differs, fix it
from the recipe above and add a new entry.

### Folio — R1 (2026-11-05)

- **Root cause:** Quantity input (PDP, cart drawer, cart page) had only `aria-label`; the discount/zip field wrapped the input in a `<label>` with an empty `id`.
- **Fix:** Quantity now gets `id="Quantity-<section>-<line|variant>-<suffix>"` + visually-hidden `<label for>` (`line`/`id_suffix` params for mobile/desktop/sticky copies). `field-input` generates `Input-<section>-<block>-<name>` and the label gets `for`. Price filter `min-value`/`max-value` → `Filter-price-<section>[-drawer]-min/max`.
- **Files:** `src/snippets/quantity/quantity.liquid`, `src/snippets/field-input/**`, cart item snippets, price filter
- **Verify:** `scan-feedback.py --only SF-A11Y-04`; runtime: duplicate-ID check in DevTools on PDP + cart.

### Folio — re-audit (2026-11-06)

- **Root cause:** Search inputs relying on `placeholder` only (overlay predictive search, filter popover search), icon-only search buttons with no name, and a cart shipping-rates country `<select>` whose `<label>` had no `for`.
- **Fix:** `aria-label` on those inputs/buttons (`templates.search.search_title`, the search label) and on the country select (same pattern as the province select).
- **Gotcha:** The scanner still WARNs on inputs wrapped in a `<label>` with visible text (checkbox/radio/swatch) and on the single `id="predictive-search"` — both are false positives (implicit label; the snippet renders once per page).
- **Files:** `predictive-search-base.liquid`, `action-search-field.liquid`, `filters-form*.liquid`, `cart-shipping-rates.liquid`
