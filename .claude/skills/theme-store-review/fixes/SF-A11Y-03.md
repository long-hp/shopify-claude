# SF-A11Y-03 — All images have an `alt` attribute

Requirement and how to verify: `../references/feedback-ledger.md` → `SF-A11Y-03`.
Check type: static

## Recipe (any theme)

No literal fallback alt (`'Image'`). Image/media snippets accept a fallback alt; product media fall back to `product.title`; blocks use `image.alt`.

## History

Each entry is one theme where this was fixed. On a theme built on the same base the files
are usually the same paths, so start from the newest entry; if the root cause differs, fix it
from the recipe above and add a new entry.

### Folio — R1 (2026-11-05)

- **Root cause:** The `image` snippet fell back to the literal `'Image'`, so product thumbnails got `alt="Image"`.
- **Fix:** `media` snippet now takes `fallback_alt`; product media pass `fallback_alt: product.title` (uses `media.alt` first). Hardcoded `alt: 'Image'` in `_image-2` → `image.alt`.
- **Files:** `src/snippets/media/media.liquid`, product-info-media snippets, `src/blocks/basic/_image-2/_image-2.liquid`
- **Verify:** `scan-feedback.py --only SF-A11Y-03`.
